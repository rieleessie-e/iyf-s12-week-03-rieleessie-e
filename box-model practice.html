Exercise 2: Fixed Broken Box

This box stays exactly 300px wide.

Without box-sizing: border-box, the width was 300px plus 20px padding on each side, which came to 340px. Adding box-sizing: border-box makes the padding count inside the 300px, so the total stays 300px.
